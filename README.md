# Mini Keyboard Keymap Catalog

Mini Keyboard Studio에서 내려받아 검토할 수 있는 키맵 JSON과 출처를 관리하는 개인 카탈로그입니다. 앱 코드와 키맵 데이터를 별도 저장소에서 관리합니다.

현재 16키·3다이얼(`mini-16x3`)용 6개 프로필이며, 각 프로필은 3개 레이어 × 25개 동작으로 채워져 있습니다. 현재 샘플에는 `preserve` 자리표시자가 없습니다.

| 순서 | 프로필 | 플랫폼 | 참고 |
| --- | --- | --- | --- |
| 1 | VS Code | macOS | 문서에 기초한 단축키, 현재 편집 문맥 확인 필요 |
| 2 | Modern Warfare 4 | Windows | 게임 내 키 바인딩을 맞춰야 하는 제안 |
| 3 | Forza Horizon 4 | Windows | 게임 내 키 바인딩을 맞춰야 하는 제안 |
| 4 | Codex 앱 | macOS | 앱 기능과 현재 포커스에 따라 동작 |
| 5 | Claude 앱 | macOS | 빠른 입력 단축키 설정 필요 |
| 6 | 시스템 기본 | macOS | 탐색·Safari·미디어 |

게임 프로필은 공식 기본 키 배치 검증 결과가 아닌 직접 지정할 바인딩 제안입니다. 키 누름 유지나 반복 입력이 필요한 운전/이동 동작은 실제 장치 동작과 게임 설정을 따로 확인해야 합니다. Claude 빠른 입력도 앱 설정과 일치시켜야 합니다. 출처 확인과 JSON 검증은 물리 키패드 또는 대상 앱·게임에서의 실행 검증을 뜻하지 않습니다.

## 파일 구조

- `catalog.json`: 앱이 읽는 버전 1 카탈로그. 프로필 경로와 정확한 파일 바이트의 SHA-256, 플랫폼, 분류, 태그를 포함합니다.
- `keymaps/`: `mini-keyboard-studio` 프로필 원본입니다. 기존 6개 파일은 버전 2 그대로 유지합니다. 검증기는 앱에서 내보낸 버전 3 파일(연결 앱 `applicationId`, 선택적 동작 이름 `label` 80자 이하)과 기존 버전 1·2를 모두 지원합니다. 기존 파일은 검증 시 버전 3으로 정규화됩니다.
- `sources/index.json`: 프로필과 단축키 근거 파일의 연결입니다. 경로는 모두 저장소 루트 기준입니다.
- `sources/*.json`: 문서 링크, 키 조합, 적용 조건, 검증 한계를 기록한 근거입니다.
- `scripts/entries.mjs`: 목록 순서·플랫폼·분류·태그·배포 버전의 편집 원본입니다.
- `tools/`: 앱의 순수 데이터 검증 코드 사본입니다. 출처는 [tools/PROVENANCE.md](tools/PROVENANCE.md)를 참고하세요.

## 기존 키맵 수정

Node.js 24 이상이 필요하며 외부 패키지 설치는 필요 없습니다.

1. `keymaps/`의 프로필을 수정하고 해당 프로필의 `updatedAt`을 갱신합니다. `id`는 유지합니다.
2. 변경 근거와 적용 조건을 `sources/`에 반영합니다. 새 사실을 확인했다면 실제 확인 날짜도 갱신합니다.
3. `scripts/entries.mjs`에서 해당 항목의 `version`을 올립니다. 예: `1.0.0` → `1.0.1`.
4. 아래 명령으로 카탈로그를 재생성하고 검증합니다.

```sh
npm run update
npm test
```

`update`는 이름·설명·ID·모델을 프로필에서 읽고 원본 파일 바이트의 SHA-256과 카탈로그 갱신 시각을 계산합니다. `catalog.json`의 해시를 직접 편집하지 마세요. 프로필 파일의 공백이나 줄바꿈만 바뀌어도 다시 생성해야 합니다.

5. `git diff`에서 프로필·근거·버전·카탈로그를 검토한 후 함께 커밋하고 푸시합니다. GitHub Actions가 동일한 검증을 실행합니다.

## 새 키맵 추가

1. `keymaps/sample-새이름.json`에 유효한 프로필을 추가합니다. 파일명·경로는 영문 소문자·숫자·`-`·`_`만 사용하고, 중첩 폴더도 허용합니다. 빈 경로 구간이나 `..`는 허용하지 않습니다.
2. `id`는 중복되지 않는 100자 이하 영문 소문자·숫자·하이픈 슬러그로 지정합니다. 이름은 80자 이하, 설명은 1,000자 이하입니다.
3. `scripts/entries.mjs`에 항목을 추가합니다. `platform`은 `mac` 또는 `windows`, `category`는 `development`·`assistant`·`game`·`system`·`other`, 태그는 8개 이하·각 32자 이하입니다. 버전은 `1.0.0`부터 시작합니다.
4. `sources/`에 근거 파일을 추가하고 `sources/index.json`의 `datasets`에 저장소 루트 기준 경로를 등록합니다.
5. `npm run update`와 `npm test`를 실행하고 변경 파일을 함께 커밋합니다. 목록은 현재 6개이며 검증기는 향후 추가도 지원합니다. 6개를 기준으로 한 테스트 기대값은 목록 확장 시 함께 갱신합니다.

## 앱에서 사용

카탈로그 위치는 `kyungtaek/mini-keyboard-keymap-catalog`의 `main` 브랜치 루트 `catalog.json`입니다. 비공개 저장소이므로 GitHub 읽기 권한이 있는 인증이 필요합니다. 토큰을 JSON, README, 커밋 또는 공유 URL에 넣지 마세요.

앱에서 카탈로그를 읽은 뒤 프로필과 SHA-256을 확인하고 편집기에 불러와 검토합니다. JSON 다운로드·편집기 불러오기와 실제 키패드에 쓰기는 별도 단계입니다. 키패드 적용 전 플랫폼·모델·레이어·게임 및 앱 설정을 확인하세요. 이 저장소의 스크립트는 HID 명령이나 장치 쓰기를 실행하지 않습니다.
